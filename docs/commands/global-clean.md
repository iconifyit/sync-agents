# `sync-agents global clean`

Remove every sync-agents-owned artifact from per-tool global
directories — per-artifact symlinks and concat files — and prune
empty parents. The canonical `~/.agents/` tree is never touched.

## Synopsis

```text
sync-agents global clean [--targets t1,t2] [--dry-run] [--global-root PATH]
```

## Safety contract

`global clean` removes only files and links it can prove belong to
sync-agents. Two checks guard every removal:

1. **Symlinks are removed only if their target resolves inside the
   global root.** A user-curated symlink pointing somewhere else
   (a personal note linked into `~/.claude/rules/`, say) is left
   alone.
2. **Regular files are removed only if their head bytes carry the
   sync-agents banner.** Concat outputs always start with
   `<!--\nGenerated by sync-agents`; user-written files don't. A
   file at a concat destination without the banner is preserved
   with a `skip non-sync-agents file` warning.

If either check fails, the item is left alone. This is the principled
inverse of `global sync`'s "fail fast on conflict" posture — clean
errs on the side of preservation, sync errs on the side of detection.

## What gets removed

- **Per-artifact symlinks** under each tool's per-scope dir
  (`~/.claude/`, `~/.codeium/`, `~/.cursor/`, `~/.github/copilot/`,
  `~/.codex/`) — whether or not the underlying canonical artifact
  still exists.
- **Concat files** that carry the banner —
  `~/.codeium/windsurf/memories/global_rules.md`,
  `~/.github/copilot/instructions.md`, `~/.codex/instructions.md`,
  and any future banner-bearing concat targets.
- **Managed regions in `~/.claude/CLAUDE.md`**: the rule `@`-import block and the `AGENTS.md` mirror block, every occurrence of each. Text outside their markers is kept; the file is removed only when nothing else remains.
- **Empty directories** left behind after the removals: the
  per-subdir parents (`rules/`, `skills/`, `commands/`,
  `global_workflows/`, `memories/`) get rmdir'd if they end up
  empty, and so does the per-tool root (`.claude/` etc.) when it
  has no remaining content.

## What does NOT get removed

- Any file or directory under `~/.agents/` itself. Clean is
  read-only with respect to the canonical tree.
- User-curated symlinks (target outside `~/.agents/`).
- User-written files at concat destinations (no banner).
- Text in `~/.claude/CLAUDE.md` outside the sync-agents markers.
- Directories that still contain user-owned content after the
  removal pass.

## Flags

| Flag | Default | Effect |
|---|---|---|
| `--targets <list>` | all | Comma-separated tool IDs to clean. Other tools' dirs are not touched. |
| `--dry-run` | false | Print the planned removals prefixed with `[dry-run]`. No filesystem writes. |
| `--global-root <path>` | `$HOME/.agents` | Override the global root. |

`--dry-run` is a persistent flag inherited from `rootCmd`.

## Examples

```bash
# Clean every tool.
sync-agents global clean

# Preview without writing.
sync-agents global clean --dry-run

# Only clean Cursor (e.g. you uninstalled Cursor and want its tree gone).
sync-agents global clean --targets cursor

# Recover from a botched sync: clean then re-sync.
sync-agents global clean && sync-agents global sync
```

## Composing with `global sync`

`clean` followed by `sync` is a way to **force-rebuild** every
destination from scratch — useful after big refactors of
`~/.agents/` (renaming a skill, deleting rules) or when a previous
sync's `--force` left behind `.replaced-by-sync-agents` backup files
you want gone.

```bash
sync-agents global clean
sync-agents global sync
```

This is safer than running `sync --force` blind, because clean
preserves user-owned content (the safety contract above) while
clearing everything sync wrote.

## Exit codes

- `0` on a clean removal pass, even if some items were preserved
  due to the safety checks (they're warnings, not errors).
- non-zero only if the global root is missing (run `global init`).

Per-tool failures (a single file that can't be removed due to
permissions, say) produce warnings but don't abort the loop.

# ADR-001: Artifact custody and composition model

**Current version:** [0.0.1](./ADR-001-artifact-custody-and-composition-0.0.1.md) — Proposed, 2026-09-18

Records the founding design of a successor tool to `sync-agents`: how agentic artifacts are owned and derived (custody), and how reusable content modules compose into artifacts.

## Versions

| Version | Date | Status | Summary |
|---|---|---|---|
